# docs/user-guide/

End-user documentation for Rasik Studio. Written for developers who use the IDE, not developers who build it.

## Contents (real, written in Phase 17 — 2026-08-11; each page is honest about what's actually built vs. planned)

| File | Contents |
|---|---|
| `INSTALLATION.md` | Download, install, and first launch on Windows, macOS, and Linux |
| `GETTING_STARTED.md` | Open a workspace, explore features, first AI chat |
| `AI_FEATURES.md` | Chat, agent tasks, inline completions, code review |
| `GIT_INTEGRATION.md` | Status panel, staging, committing, AI commit messages |
| `TERMINAL.md` | Opening tabs, shell configuration, keyboard shortcuts |
| `BROWSER.md` | Using the in-IDE browser, agent browser automation |
| `SETTINGS.md` | All settings categories with descriptions and defaults |
| `KEYBOARD_SHORTCUTS.md` | Complete shortcut reference, how to customize |
| `THEMES.md` | Switching themes, installing community themes |
| `PLUGINS.md` | Installing, managing, and disabling plugins |
| `TROUBLESHOOTING.md` | Common issues and solutions |

## Writing Style

- Use plain language. Assume the reader is a developer, not an Electron engineer.
- Every feature should have at least one screenshot in the final version.
- Steps are numbered. Commands are in code blocks. Warnings use blockquotes.
