# docs/api/

Human-readable API reference for the Rasik Studio backend. The machine-readable source of truth is the OpenAPI schema auto-generated by FastAPI at `/openapi.json`.

## Contents (real, written in Phase 17 — 2026-08-11, generated against the live running backend)

| File | Contents |
|---|---|
| `REST_REFERENCE.md` | All 23 real REST endpoints, grouped by router |
| `WEBSOCKET_EVENTS.md` | All real WebSocket event types (`event_types.py`'s actual `ServerEvent`/`ClientMessage` unions) |
| `ERROR_CODES.md` | Every real `code="..."` string found in the codebase, not a speculative list |
| `AUTHENTICATION.md` | Practical token-flow/OAuth guide for API consumers — see the root `AUTHENTICATION.md` for the full design |

## Keeping Docs in Sync

Run the following after any API change to regenerate the TypeScript types and detect schema drift:

```bash
curl http://localhost:8000/openapi.json > /tmp/openapi.json
pnpm exec openapi-typescript /tmp/openapi.json -o packages/desktop-types/src/api.d.ts
```

If the generated output differs from the committed file, the API docs are out of date.
